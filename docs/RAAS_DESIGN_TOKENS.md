# RAAS 디자인 토큰 v1

이 문서는 RAAS의 시각 시스템 단일 진실 소스(Single Source of Truth)입니다. 모든 새 컴포넌트는 이 토큰을 참조해야 하며, 새 토큰 추가/변경은 [docs/decisions.md](decisions.md)에 D-NNN 항목으로 기록합니다.

원본 CSS 변수는 [raas_web.html](../raas_web.html)의 `:root` 블록에 있고, 이 문서는 그 변수에 **의도(intent)**와 **층(layer)** 라벨을 부여합니다.

---

## 0. 토큰 체계 — 3-tier 모델

```
Tier 1 — Primitive (원시값)         예: --bg0: #0d1117
   │
   ▼
Tier 2 — Semantic (의도 부여)       예: --color-bg-base: var(--bg0)
   │
   ▼
Tier 3 — Component (컴포넌트 전용)  예: .brief-card { background: var(--color-bg-elevated) }
```

**원칙:**
1. 새 컴포넌트는 **Tier 2 시맨틱 토큰만** 참조 — Primitive 직접 사용 X
2. Primitive 값 자체가 바뀌어도 시맨틱 레이어가 흡수 (다크/라이트 테마 전환 사례)
3. 토큰명은 영어 (CSS 변수 표준), 의도 설명은 한국어 (이 문서)

### 1.2 Semantic 컬러 (Tier 2)

새 컴포넌트는 이쪽만 참조:

| 시맨틱 토큰 | → 매핑 | 의도 |
|---|---|---|
| `--color-bg-base` | `--bg0` | 페이지 바닥 |
| `--color-bg-elevated` | `--bg1` | 1단계 떠 있는 면 |
| `--color-bg-elevated-2` | `--bg2` | 2단계 (카드 내부 강조) |
| `--color-bg-elevated-3` | `--bg3` | 3단계 (인터랙티브) |
| `--color-border-subtle` | `--line` | 미묘한 분리 |
| `--color-border-strong` | `--line2` | 명확한 분리 |
| `--color-text-primary` | `--text` | 본문 |
| `--color-text-secondary` | `--text2` | 부가 정보 |
| `--color-text-tertiary` | `--sub` | 라벨 |
| `--color-text-disabled` | `--dim` | 비활성 |
| `--color-interactive` | `--accent` | 클릭 가능한 모든 것 |
| `--color-interactive-soft` | `--accent-soft` | 인터랙티브 배경 hover |
| **`--color-success`** | `--green` | 긍정 신호 (D1유지율 ↑ 등) |
| **`--color-danger`** | `--red` | 부정 신호 (이탈율 ↑ 등) |
| **`--color-warning`** | `--yellow` | 주의 (z-score 경계 등) |
| **`--color-info`** | `--purple` | 알림·추천·보조 강조 |

### 1.3 사용 규칙

- ✅ "상태 색" 선택 시 항상 의미 기준: 증가 ≠ 무조건 success, 감소 ≠ 무조건 danger (지표 성격에 따라 다름)
  - DAU 감소 = `--color-danger`
  - 이탈율 감소 = `--color-success`
  - 깊은청취율 변화 = 직무·문맥별
- ✅ AI 답변·차트 라이브러리에서도 동일 토큰 참조 (룩앤필 일관성)
- ❌ 16진수 값 인라인 직접 사용 금지 (테마 전환 시 깨짐)

## 3. Spacing (간격) — 신규 도입

조화로운 간격을 위한 8 단계 스케일. CSS 변수로 노출 (Tier 2).

| 토큰 | 값 | 의도 |
|---|---|---|
| `--sp-1` | `4px` | 인접 요소 미세 분리 (아이콘과 텍스트) |
| `--sp-2` | `8px` | 작은 패딩·gap |
| `--sp-3` | `12px` | 기본 인라인 간격 |
| `--sp-4` | `16px` | 컴포넌트 내부 표준 패딩 |
| `--sp-5` | `24px` | 카드 외곽 패딩 |
| `--sp-6` | `32px` | 섹션 간 분리 |
| `--sp-7` | `48px` | 큰 그룹 분리 |
| `--sp-8` | `64px` | 페이지 외곽 |

기존 컴포넌트는 인라인 값이라 점진적 마이그레이션.

## 5. Motion (모션) — 신규 도입

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ease-quick` | `cubic-bezier(0.4, 0, 0.2, 1)` | 일반 인터랙션 (Material standard) |
| `--ease-smooth` | `cubic-bezier(0.65, 0, 0.35, 1)` | 큰 영역 이동 |
| `--dur-fast` | `0.12s` | 호버·포커스 |
| `--dur-base` | `0.2s` | 메뉴·드롭다운 |
| `--dur-slow` | `0.4s` | 모달·페이지 전환 |

## 6. Z-index (레이어) — 현재 구조 문서화

CSS 변수로 새로 도입하기보다 명시 규약만 정함:

| 레이어 | 값 | 사용처 |
|---|---|---|
| Base | `0~10` | 정상 흐름 |
| Dropdown | `100` | 작은 팝오버 |
| Sticky header | `200` | 고정 헤더 (필요 시) |
| Overlay | `300` | KPI 패널 모바일 드로어 |
| Modal | `500` | hist-modal·profile-modal·admin-modal·stats-modal |
| Toast | `700` | 알림 (현재 없음) |
| Auth gate | `900` | 로그인 게이트 (최상위) |

## 9. 레퍼런스 보드 — 영감의 출처

RAAS의 시각 언어는 다음 제품에서 영감을 받았습니다. 의식적으로 닮으려 한 게 아니라, **사내 분석 도구가 자연스럽게 수렴하는 형태**를 따라간 결과:

### GitHub Dark
- **무엇:** `--bg0: #0d1117`, 미묘한 보더, 모노 폰트의 수치 강조
- **왜:** 개발자에게 친숙한 다크 톤. 장시간 응시해도 피로 적음.

### Linear
- **무엇:** 깨끗한 카드 + 강한 키보드 친화 + 미니멀한 모달
- **왜:** 도구다움. 장식 최소, 정보 우선.

### Vercel (Geist 디자인)
- **무엇:** 액센트 컬러 1개 + 회색 스케일 + 거의 모노톤
- **왜:** 신뢰감. 색 남발 없음. RAAS의 `--accent: #4f8ef7` 단일 액센트 전략.

### Stripe Dashboard
- **무엇:** 데이터 밀도 ↑, 표 디자인 정교, 작은 인터랙션 정성
- **왜:** 분석 도구의 정수. 화면당 정보량 vs 가독성의 균형.

### Anthropic Claude.ai
- **무엇:** 채팅 흐름·메시지 풍선·환영 화면 패턴
- **왜:** RAAS의 자연어 챗 UX는 이 흐름을 차용. 입력창 위치·SSE 토큰 스트리밍·답변 정렬.

### 차이점
- **차트 색 팔레트는 자체 정의** (`--accent`/`--green`/`--red`/`--yellow`/`--purple`) — Splunk·Grafana의 형광색 회피
- **장식 요소 없음** (배경 패턴·그라데이션 최소) — 비즈니스 도구 톤 유지

## 10. 사용 가이드

### 새 컴포넌트 작성 시 체크리스트

- [ ] 색은 Tier 2 시맨틱 토큰만 (`var(--color-*)`)
- [ ] 폰트 크기는 `--fs-*` 변수 (인라인 `font-size: 14px` 금지)
- [ ] 간격은 `--sp-*` 또는 일관된 8의 배수
- [ ] 라운드는 `--rad-*` 변수
- [ ] 트랜지션은 `--ease-*` + `--dur-*` 조합
- [ ] 모달이면 z-index 500 / 토스트 700 / 게이트 900 (CSS 클래스로 추적)

### 토큰 추가/변경 절차

1. 새 토큰의 의도·layer·매핑을 [docs/decisions.md](decisions.md)에 `D-NNN` 항목으로 제안
2. 본 문서 1~6절 갱신
3. [raas_web.html](../raas_web.html) `:root` 블록에 CSS 추가
4. PR에 변경 전후 차이 명시

## 11. 알려진 부채 (점진 정리 대상)

| 항목 | 현황 | 권장 정리 시점 |
|---|---|---|
| 컴포넌트별 인라인 spacing (`padding: 14px 18px` 등) | 다수 존재 | 새 컴포넌트 작성 시 `--sp-*` 사용, 기존은 그대로 |
| 컴포넌트별 인라인 색 (16진수) | 그래프·차트 일부 | 새 차트 9종 도입 시 시맨틱 토큰화 |
| 16진수 직접 사용 `#13181f` 등 | 1~2건 추정 | 발견 시 PR로 정리 |

## 12. 한 줄 요약

> **Primitive(원시) → Semantic(의도) → Component(전용) 3층. 새 컴포넌트는 시맨틱만 본다. 색은 의도 기준으로, 간격은 8의 배수, 모션은 0.12~0.4초.**
