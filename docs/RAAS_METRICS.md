# RAAS 측정 지표 v1

이 문서는 RAAS 다음 4주(2026-06-15 ~ 2026-07-12) 기간의 성공을 측정하기 위한 단일 진실 소스(Single Source of Truth)입니다.
모든 의사결정은 이 문서의 지표를 근거로 판단합니다.

---

## 1. 북극성 지표 (NSM)

### 주간 활성 분석 사용자 (WAAU, Weekly Active Analytics User)

- **정의**: 최근 7일 내 `view_briefing` 이벤트가 1회 이상 발생한 고유 사용자 수
- **계산식**: `COUNT(DISTINCT user_id) WHERE event = 'view_briefing' AND timestamp >= NOW() - 7d`
- **측정 도구**: PostHog
- **갱신 주기**: 실시간 (대시보드에서 일 단위 확인)
- **4주 목표**: 인터뷰 대상 5명 중 **3명 이상** (60%)

### NSM 선택 이유

- "행동 변화"(편성 조정·코너 개입)는 측정 불가능 → 선행 지표로 부적합
- WAAU는 **습관 형성**을 측정. 사내 도구가 살아남는 핵심 신호
- 단점: 의례화(ritualization) 함정 — 사용량은 있지만 가치가 없는 상태가 가능
- → **반드시 가드레일 지표와 함께 본다** (5절 참조)

## 2. Leading 지표 (주간 추적)

선행 지표는 NSM이 움직이기 전에 나타나는 신호. 매주 금요일 리뷰에서 확인.

### 2.1 `ask_ai / view_briefing` 비율 ★ D3 결정 신호

- **정의**: 브리핑 카드를 본 사용자가 그 자리에서 AI 챗에 추가 질문을 던지는 비율
- **계산식**: `COUNT(ask_ai) / COUNT(view_briefing)` (같은 세션 내 30분 안)
- **의미**: AI 챗이 "1차 표면"인지 "보조 도구"인지 가르는 결정적 신호
- **해석 기준**:
  | 비율 | 해석 |
  |------|------|
  | > 0.5 | AI 챗이 1차 표면일 가능성 ↑ → D3 재검토 |
  | 0.1 ~ 0.5 | AI 챗은 강력한 보조 도구 |
  | < 0.1 | AI 챗은 부차적, 차트가 1차 표면 |

### 2.2 `share_view / view_briefing` 비율

- **정의**: 브리핑을 본 사용자가 캡처/링크 공유까지 진행하는 비율
- **의미**: "회의 도구"로의 진화 신호
- **목표(4주 끝)**: ≥ 30%

### 2.3 `chart_click` 발생률

- **정의**: 브리핑 카드 노출 대비 차트 인터랙션(hover/zoom/click) 발생률
- **의미**: 차트가 "보는 것"에서 "다루는 것"으로 전환됐는지
- **목표(4주 끝)**: ≥ 40%

### 2.4 차트 `chart_type` 적합률

- **정의**: AI가 데이터 모양·의도에 맞춰 선택한 차트 종류가 적절한 비율
- **측정 방식**: 30건 샘플 수동 라벨링 (Week 4)
- **목표(4주 끝)**: ≥ 80%

## 3. Outcome 가드레일 (월 1회)

NSM이 의례화 함정에 빠지지 않았는지 확인하는 사후 지표.

### 회의 준비 시간 절감 (분)

- **측정 방식**: 4주 차 마지막 날 5명 설문 (1문항)
  > "지난 4주 동안 RAAS로 회의/보고 준비 시간이 얼마나 줄었나요? (분 단위, 줄지 않았다면 0)"
- **해석 기준**:
  - 평균 ≥ 30분 → 가치 검증 시작, 다음 분기 확대 추진
  - 평균 1~29분 → 가치는 있지만 약함, 흐름 재검토
  - 평균 0 → NSM이 올라가도 의례화 의심, 즉시 흐름 재설계

## 4. 4주 끝 성공 기준 (이중)

5주차 월요일(2026-07-13) 측정.

### 4.1 재방문 기준
- [ ] 5명 중 **3명 이상이** 5주차 월요일에 자발적으로 브리핑 카드를 연다
- 측정: PostHog `view_briefing` 이벤트, 사용자별 발생 여부

### 4.2 행동 기준
- [ ] 5명 중 **3명 이상이** 다음 중 1건 이상 수행
  - `share_view` (캡처/링크 공유)
  - `ask_ai` (브리핑 카드에서 챗 호출)
  - `chart_click` (차트 인터랙션)

**두 기준을 모두 충족해야 4주 성공.** 재방문만으로는 의례화 위험.

### 4.3 차트 자동 선택 품질
- [ ] `chart_type` 적합률 ≥ 80% (30건 샘플 수동 평가)
- [ ] "다른 차트로 보여줘" 재요청 시 AI가 의미 있는 대안 제시

### 4.4 D3 결정 신호 확보
- [ ] `ask_ai / view_briefing` 비율 1차 측정값 확보 (해석 가능한 표본 ≥ 50건)

### 4.5 가드레일
- [ ] 5명 설문 응답률 100%, 평균 절감 분 수 양수

## 5. D3 (AI 챗의 위상) 결정 규칙

ChatGPT가 강조한 이번 라운드 핵심 통찰:
> "현재 로드맵에서 가장 중요한 실험은 사용자들이 월요일 브리핑을 본 뒤 자연스럽게 AI에게 추가 질문을 하는가를 관찰하는 것이다."

이 신호를 객관적으로 받기 위한 규칙.

| `ask_ai / view_briefing` | 다음 분기 방향 |
|--------------------------|----------------|
| > 0.5 | **챗 중심 강화** — 브리핑 카드 안에서 챗 흐름을 더 부드럽게, 챗이 차트를 트리거하는 구조 검토 |
| 0.3 ~ 0.5 | **챗-차트 동등 표면** — 카드 = 차트 + 챗 입력 한 화면에 |
| 0.1 ~ 0.3 | **챗은 강력한 보조** — 챗은 카드 옆 부수 단추로 남김 |
| < 0.1 | **챗 우선순위 하향** — 챗 진입을 더 깊은 곳으로, 차트 자동 갱신 강화 |

표본 부족(< 50건)이면 결정 보류 + 5주차 추가 관측.

## 6. 측정·검토 루틴

| 주기 | 누가 | 무엇을 |
|------|------|--------|
| 매일 | 1인 개발자 | PostHog 라이브 카운트 1회 확인 (30초) |
| 매주 금요일 15분 | 1인 개발자 | Leading 4개 + WAAU 추이 1주 리뷰 |
| Week 4 끝 | 1인 개발자 | 4주 끝 성공 기준 5개 전체 평가 |
| Week 4 끝 | 5명 사용자 | 가드레일 설문 1문항 응답 |

## 7. NSM·지표 변경 정책

이 문서는 **4주가 끝날 때까지 잠금**. 중간에 NSM/임계값을 바꾸면 자기기만 위험.

다음 경우에만 변경 허용:
- PostHog 이벤트 정의 자체가 잘못되었음이 발견될 때 (Week 1 내 발견 시)
- 인터뷰에서 NSM 후보가 명백히 잘못된 페르소나를 가정하고 있었음이 드러날 때

변경 시 [docs/decisions.md](docs/decisions.md)에 사유 기록.
