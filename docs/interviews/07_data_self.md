# 07. 데이터 — 자가 회고 노트 (apollo)

> 공통 원칙·도입·마무리: [README.md](README.md)
> 대상: **본인(apollo) 자가 회고**. 외부 인터뷰가 아닌 자기 작성용.

---

## 페르소나 가설

- **시점**: Analyst 파워유저. 다른 6개 직무와 **성격이 다름**
- **주기**: 매일·실시간. 데이터 자체가 일상
- **목적**: 숫자 신뢰성 검증·방법론 점검·자유 탐색·다른 팀 수요 파악·시스템 개선
- **니즈**: "오늘 알아야 할 걸 큐레이션해줘"(떠먹이기) **X** → 유연한 파워유저 모드 + 검증 도구
- **고통 가설**: 시스템을 본인이 만들기 때문에 자기 객관화가 어렵다. 다른 팀이 무엇을 물어볼지 미리 알기 어려워서 "분석가가 자기 시점"으로 만든 도구를 다른 직무가 못 쓰는 함정에 빠지기 쉬움

---

## 왜 외부 인터뷰가 아닌가

[project_role_personas memory](../../CLAUDE.md) — 데이터 직무는 다음 이유로 별격:

1. **메타 위치**: 시스템을 만드는 사람이므로 RAAS의 영향이 가장 큼. 같은 인터뷰 질문이 자기 자신에게는 의미가 다름
2. **떠먹이기 X**: 다른 6직무는 "오늘 알아야 할 걸 큐레이션해줘" 모드지만 데이터는 자유 탐색·검증 모드. 같은 인터뷰 표 비교 불가
3. **온보딩 분리**: 프로필·온보딩 흐름 자체가 다르게 설계되어야 함

→ 자가 회고로 **자기 사용 패턴을 글로** 남겨, 다른 5명 인터뷰 결과와 **대비**해 본다.

---

## 자가 회고 6질문

### Q1. 지난주 월요일 아침 30분 — 본인의 실제 행동

기록 항목:
- 출근 직후 30분 시간순 단계
- 사용 도구 이름과 순서
- "왜 그걸 그 순서로 봤나" 자가 분석

### Q2. 데이터 출처와 조합

기록 항목:
- 실시간으로 의지하는 데이터 소스 N개
- 매번 조합하는 패턴
- 시간이 가장 많이 드는 단계 (병목)

### Q3. 누구에게 어떻게 전달

기록 항목:
- 이번 주 누가 본인에게 무엇을 물었는가
- 답변에 걸린 시간·다시 물어본 횟수
- 정형 보고서 vs 즉답 비율

### Q4. 지난 한 달 가장 자주 한 질문 3개

기록 항목:
- 본인이 본인에게 한 질문 (탐색·검증)
- 다른 팀이 본인에게 한 질문 (수요)
- **차이점** 분석 — 다른 팀 수요가 본인 탐색과 얼마나 겹치는가

### Q5. 가장 짜증난 순간

기록 항목:
- 사건·해결 방식·빈도
- "이런 도구가 있었으면" 가정

### Q6. RAAS의 본인 사용 — 솔직한 자가 평가

기록 항목:
- 본인이 본인 시스템을 매일 쓰는가
- 안 쓴다면 진짜 이유 (다른 도구가 빠른가, 익숙한가)
- 다른 6직무에 권하기 어려운 부분

---

## 5명 인터뷰 비교 시 자가 회고 활용법

5명 결과가 모이면 본인 회고를 **대조군**으로 쓴다:

1. **공통 패턴 vs 본인**: 5명이 공통으로 말한 것 중 본인은 다르게 한 것 → 본인 시점 편향 식별
2. **본인이 당연한 것 vs 5명이 모르는 것**: 본인은 매일 쓰는 지표를 5명은 처음 듣는다면 **지식 격차 = 온보딩 과제**
3. **5명의 질문 vs 본인의 답변 시간**: 5명 Q4 질문 패턴이 본인이 답하는 데 오래 걸리는 것이라면 → 자동화 우선순위

## 작성 시점

5명 인터뷰 **시작 전**(지금)에 1차 작성 → 5명 끝난 후 2차 갱신.
1차 작성 시 **다른 5명 답변을 추측하지 말 것**. 본인 행동만 정직하게.
