## 5명 인터뷰 권장 조합

**필수 사수:** 제작PD 1명 + CP 또는 총괄관리 1명 (의사결정 라인 확보)

**권장 구성 (조합 A — 운영 중심)**
- 제작PD 2명 (파워FM 또는 러브FM × 1, 고릴라M 또는 픽채널 × 1)
- 편성PD 1명
- CP 1명
- 마케팅 1명

**권장 구성 (조합 B — 전략 중심)**
- 제작PD 1명
- CP 1명
- 총괄관리 1명
- 플랫폼전략 1명
- 마케팅 1명

**권장 구성 (조합 C — 통합 진단 중심, 서비스 운영 포함)**
- 제작PD 1명
- CP 1명
- 총괄관리 1명
- 서비스 운영 1명
- 마케팅 또는 플랫폼전략 1명

> 데이터 직무는 apollo 자가 회고로 대체 (07 파일).
> 서비스 운영(08)은 청취 감소의 원인 분석(콘텐츠 vs 서비스) 시 핵심 시점이라 통합 진단 중심 조합에서 사수.

## 모든 인터뷰에 공통 적용

### 핵심 원칙 (Mom Test)
- 과거 행동만 묻는다. 미래 의도 X
- 솔루션 평가 X (RAAS를 보여주거나 평가받지 않음)
- 추상 일반론("보통은…")이 나오면 "지난주에는요?"로 끌어옴

### 30분 시간 배분 (직무별 미세 조정은 각 파일 참조)

| 시간 | 단계 | 내용 |
|------|------|------|
| 0:00 ~ 2:00 | 도입 | 인사·목적 설명·녹음 동의 |
| 2:00 ~ 7:00 | Q1 | 월요일 아침 실제 행동 |
| 7:00 ~ 12:00 | Q2 | 데이터 출처와 조합 방식 |
| 12:00 ~ 17:00 | Q3 | 누구에게 어떻게 전달 |
| 17:00 ~ 22:00 | Q4 | 가장 자주 묻는 질문 3개 |
| 22:00 ~ 26:00 | Q5 | 가장 짜증나는 순간 |
| 26:00 ~ 29:00 | Q6 | RAAS를 안 쓰는(잘 안 쓰는) 진짜 이유 |
| 29:00 ~ 30:00 | 마무리 | 감사·다음 단계 안내 |

> 시간이 밀리면 Q4·Q5 줄임. **Q1·Q2·Q6는 사수.**

### 도입 스크립트 (직무 무관 공통)
> 안녕하세요, 시간 내주셔서 감사합니다.
> 오늘 30분 동안 SBS 라디오 데이터를 평소 어떻게 다루시는지 듣고 싶어서 왔습니다.
> **RAAS 시연이나 평가가 아닙니다.** 어떤 도구를 쓰시든 평소 행동을 그대로 말씀해 주시면 됩니다.
> 정답이 없는 자리이고, 사소해 보이는 디테일이 가장 값집니다. 짜증나는 순간일수록 좋습니다.
> 메모를 위해 녹음 켜도 괜찮을까요? (녹음은 제 메모용·외부 미공유)

### 마무리 스크립트 (공통)
> 정말 도움이 됐습니다. 마지막으로 제가 못 물은 것 중 꼭 말씀하고 싶은 게 있으실까요?
> (있으면 듣고) 다음 달쯤 새 버전 들고 다시 30분 부탁드릴 수 있을까요? 그땐 시연 보여드리고 피드백 받고 싶습니다.
